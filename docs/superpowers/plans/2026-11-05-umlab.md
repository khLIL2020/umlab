# UMLab Implementation Plan

Goal: implement the supplied UMLab specification as a complete static React/TypeScript app.
Architecture: one serializable Project, pure validation and mutation functions, history-backed React store; React Flow class canvas and SVG sequence canvas.
Stack: Vite react-ts, React Flow, Tailwind, Vitest. No server or accounts.
Spec: user attachment Pasted text.txt (2026-11-05).

## Constraints and decisions
- Native implementation authorized by user response to direct-build proposal.
- Public repository name: umlab; GitHub authentication must work before publication.
- Use relative Vite base './' so the exact build works under /umlab/ and at a domain root.
- Return messages are responses, not method invocations; exclude from method-existence checks.
- Inherited methods are callable; unknown argument types do not produce speculative type warnings.

## Review focus
Corrupt imports and missing endpoints; persistence failures; delete/undo preserving references; overloaded/inherited methods; reviewer preventing keyboard and drag edits.
